# Paquete DI v2 — Introducción a la inversión en acciones

Contenido:

- `Storyboard_Master_v2.md`: fuente canónica de producción para IA y humanos.
- `Storyboard_Produccion_v2.pptx`: vista humana del storyboard, una diapositiva por pantalla P01–P47.
- `storyboard_data_v2.json`: estructura machine-readable del storyboard.
- `Calculadora_valorizacion_dividendos_v2.xlsx`: descargable con fórmulas abiertas, casos de prueba y fuentes/supuestos.
- `Descargables_Master_v2.md`: fuente canónica de los descargables.
- `Descargables_Produccion_v2.docx`: versión editable para revisión/diseño humano.
- `QA_Matriz_v2.md`: control de requisitos y aceptación.

Nota: los ejemplos usan emisores ficticios y no constituyen recomendación de inversión.
